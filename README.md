# ⚡ Getting Started

## Clone Repository

```bash
git clone https://github.com/pragatipandey25/Pragati-Portfolio.git
```

## Navigate

```bash
cd Pragati-Portfolio
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# 📦 Production

Create production build

```bash
npm run build
```

Run production

```bash
npm run start
```
